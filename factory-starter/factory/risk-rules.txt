# tier  pattern
# Patterns are bash [[ ]] globs matched against the path from the repo root,
# and * also matches "/". For each changed file the highest matching tier wins;
# a file that matches nothing is R1. The change takes the highest tier of any file.
# CI reads this file from the base branch, so a pull request cannot relax its own gate.

# R0: cannot break the product
R0 docs/*
R0 work/*
R0 *.md
R0 product/INBOX.md
R0 memory/observations/*

R2 CLAUDE.md
R2 product/BRIEF.md

R2 planning/*
R2 contracts/*
